# 💎 Array Patterns Visualizer — Glassy Premier DSA Masterclass

An interactive, high-performance visual learning platform for **12 Array Data Structure Patterns** and **60 Curated LeetCode Problems**. Features real-time step-by-step array animations, synchronized code tracking across **JavaScript, Python, Java, and C++**, live variable state watch, parallel dry run cards, and pattern mastery quizzes with detailed solution explanations.

---

## 🌟 Key Features

- **12 Core Array Patterns**:
  1. Array Traversal & Accumulation
  2. Prefix & Suffix Sum
  3. Fixed-Size Sliding Window
  4. Dynamic-Size Sliding Window
  5. Two Pointers (Inward & Outward)
  6. Binary Search & Search Space Reduction
  7. Kadane's Algorithm & Dynamic Subarray
  8. Hash Table / Frequency Map Memory
  9. 2D Matrix Traversal & In-Place Rotation
  10. Cyclic Sort & Index Mapping
  11. Dutch National Flag & Multi-Pointer Partition
  12. Greedy Choice & Jump Reachability

- **60 Curated LeetCode Problems**: 5 benchmark problems per pattern with full implementations in **JavaScript, Python, Java, and C++**.
- **⚡ Dual Execution Engines**: Toggle instantly between **⚡ Optimized Pattern Engine** and **🐢 Brute Force Engine** (e.g. $O(N)$ vs $O(N^2)$).
- **💎 Glassy Premier Design System**: Ultra-luxury dark glassmorphic UI with vibrant neon glow accents, smooth micro-animations, and responsive 3D array elements.
- **📐 Resizable & Collapsible Side Panels**: Drag splitters up to **70% screen width** or collapse panels instantly with buttons or keyboard shortcuts (<kbd>Ctrl</kbd> + <kbd>[</kbd> and <kbd>Ctrl</kbd> + <kbd>]</kbd>).
- **🔍 Synchronized Code Line Tracking & Parallel Live Dry Run**: Highlighted code lines with real-time variable watch pills (`i`, `left`, `right`, `sum`, `running`, `write`, `res`).
- **🧠 120 Pattern Mastery Quiz Questions**: 10 interactive multiple-choice questions per pattern with instant score tracking and solution explanations.
- **✏️ Custom Test Case & Zoom View Controls**: Input custom arrays or zoom canvas from **50% to 200% scale**.

## 🚀 Quick Start

Simply clone the repository and launch a static HTTP server:

```bash
git clone https://github.com/venkatesh7975/Array_Visualizer.git
cd Array_Visualizer
python -m http.server 3000
```

Then open `http://localhost:3000` in your web browser.

## ⌨️ Keyboard Shortcuts

| :--- | :--- |
